## Content Guidelines

### Tone & Voice
- Confident and authoritative
- Focused on outcomes, not features
- Use specific numbers and metrics
- Speak to aspirations and growth

### SEO Optimization
- Naturally include primary keywords in H1, H2 tags
- Use semantic variations throughout
- Include location modifiers for local search
- Optimize images with descriptive alt text

### Performance Notes
- Lazy load images below fold
- Preload hero assets
- Use WebP with fallbacks
- Inline critical CSS
- Target <3 second load time
